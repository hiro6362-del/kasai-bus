# 葛西バス

葛西トラックターミナル周辺のバス停(葛西トラックターミナル・臨海町三丁目・中央卸売市場葛西市場前・中左近橋・堀江団地)から、葛西駅・西葛西駅・中葛西五丁目へ向かう都営バスを、今の時刻以降で表示するWebアプリです。

- 公開ページ: https://hiro6362-del.github.io/kasai-bus/
- 時刻の出典: [都営バス 停留所時刻表](https://tobus.jp/sp/blsys)(2026年10月25日に取得)
- 平日/土曜/休日ダイヤを日付と祝日から自動で選びます

## 時刻データの更新

`tools/raw/<停留所ID>_<系統コード>_<のりば>.txt` を書き換えて `tools/make.sh` を実行すると、`index.html` が作り直されます。
